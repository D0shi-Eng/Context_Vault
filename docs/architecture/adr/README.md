# Architecture Decision Records

Architecture Decision Records document significant technical, security, governance, and compatibility decisions.

## Status values

- Proposed
- Accepted
- Superseded
- Deprecated
- Rejected

## Required sections

1. Context
2. Decision
3. Alternatives considered
4. Security consequences
5. Operational consequences
6. Verification
7. Residual risks

Accepted records are immutable. A later decision supersedes an earlier record instead of silently rewriting its history.

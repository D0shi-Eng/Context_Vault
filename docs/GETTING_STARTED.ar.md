# البدء مع ContextVault

يغطي هذا الدليل تثبيت ContextVault من المصدر، وبناءه، وتشغيله كخادم MCP
فوق `stdio`، وإدارة دورة استخدام كاملة وآمنة. للمعمارية ونموذج الأمان راجع
[README.ar.md](../README.ar.md)؛ وتفاصيل الربط وجداول الأخطاء في
[INTEGRATION.md](INTEGRATION.md).

## 1. المتطلبات

- **Node.js إصدار 24 أو أحدث** (يتطلب حقل `engines` في `package.json`
  الإصدار `>=24.0.0`). تحقق بالأمر `node --version`.
- **pnpm الإصدار 11.19.0** (مثبّت عبر حقل `packageManager` في
  `package.json`).
- نسخة مصدرية محلية من هذا المستودع. لا توجد حزمة npm منشورة ولا خدمة
  مستضافة؛ والتثبيت من المصدر هو الطريقة الوحيدة المدعومة.
- نظام تشغيل بنظام ملفات محلي (ويندوز أو لينكس أو macOS). لا يفتح الخادم
  أي منفذ شبكي إطلاقًا.

## 2. التثبيت من المصدر

انسخ المستودع إلى مجلد باسم `ContextVault`. يتطلب الوصول إلى المستودع
حاليًا حسابًا مصرّحًا له:

```bash
git clone https://github.com/D0shi-Eng/Context_Vault.git ContextVault
cd ContextVault
```

```bash
corepack enable
corepack prepare pnpm@11.19.0 --activate
```

إذا لم يتوفر corepack في توزيع Node لديك، ثبّت pnpm مباشرة:

```bash
npm install -g pnpm@11.19.0
```

ثم ثبّت الاعتمادات المقفلة:

```bash
pnpm install --frozen-lockfile
```

## 3. البناء

```bash
pnpm run build
```

البناء ترجمة TypeScript صارمة (`tsc -p tsconfig.build.json`) تنتج مخرجات
ESM في `dist/`، ونقطة دخول الخادم هي `dist/main.js`.

اختياريًا قبل أول استخدام — شغّل بوابة الجودة المحلية الكاملة:

```bash
pnpm run check
```

## 4. تشغيل خادم MCP عبر stdio

الخادم عملية ابنة لمضيف MCP لديك؛ يقرأ JSON-RPC من المدخل القياسي ويكتب
إلى المخرج القياسي. لا تتوقع مخرجات نصية تفاعلية عند تشغيله؛ فهو يتحدث
JSON-RPC فقط.

تُصرَّح جذور مساحة العمل عند بدء التشغيل:

```bash
node dist/main.js --workspace-root=demo=C:/Projects/ExampleWorkspace
```

والجذور المتعددة بتكرار العلم:

```bash
node dist/main.js --workspace-root=alpha=C:/Projects/Alpha --workspace-root=beta=D:/Work/Beta
```

قواعد الجذور:

- الصيغة: `--workspace-root=<root-id>=<absolute-path-to-directory>`.
- يطابق `<root-id>` النمط `/^[a-z][a-z0-9_-]{0,63}$/`؛ والتكرار مرفوض.
- يجب أن يكون المسار مطلقًا وموجودًا ومجلدًا؛ وأي جذر يوحّد مساره إلى جذر
  نظام الملفات (`/` أو `C:\`) يُرفض.
- الجذور ثابتة عند بدء التشغيل. لا يوجد تسجيل أثناء التشغيل.
- عدم تصريح أي جذر وضع صحيح: يبدأ الخادم ويفشل كل قراءة بإغلاق آمن برمز
  `CV_AUTHORIZATION_DENIED`.

## 5. تهيئة عميل MCP عام

صيغة محايدة تجاه العميل — وجّه `command` إلى مُشغّل Node لديك و`args` إلى
نقطة الدخول المبنية:

```json
{
  "mcpServers": {
    "contextvault": {
      "command": "node",
      "args": [
        "C:/Projects/ContextVault/dist/main.js",
        "--workspace-root=project=C:/Projects/ExampleWorkspace"
      ]
    }
  }
}
```

على ويندوز، هرّب مسارات JSON بخطوط مائلة للأمام (`C:/…`) أو بخطوط مائلة
للخلف مضاعفة (`C:\\…`).

## 6. دورة استخدام آمنة كاملة

مرجع المصدر المستخدم في هذه الدورة:

```json
{ "source": { "kind": "workspace_file", "rootId": "project", "path": "docs/notes.md" } }
```

1. **Inspect** — بيانات وصفية بلا محتوى:

   الأداة `contextvault_inspect` والمدخل مرجع المصدر أعلاه. تعيد
   `sourceId` و`sourceDigest` و`mediaType` و`bytes` و`sensitivity`
   و`secretRisk` و`supportedSelectors` و`inspectedAt`. الاستجابة لا تحتوي
   محتوى المصدر أبدًا.

2. **Prepare** — مغلف بنيوي محدود مع منحة استرجاع ضيقة:

   الأداة `contextvault_prepare`:

   ```json
   {
     "source": { "kind": "workspace_file", "rootId": "project", "path": "docs/notes.md" },
     "retrieval": { "allowedSelectorTypes": ["line_range"], "maxBytes": 4096 }
   }
   ```

   تعيد `envelopeId` ورمز `retrieval.capability` اختياريًا. يخزن الخادم
   بصمة SHA-256 لهذا الرمز فقط.

3. **Retrieve** — فقط عند الحاجة الصريحة للنص الدقيق:

   الأداة `contextvault_retrieve`:

   ```json
   {
     "capability": "<from-prepare>",
     "selector": { "kind": "line_range", "startLine": 1, "endLine": 40 }
   }
   ```

   تعيد مقتطفًا واحدًا محدودًا مع `excerptDigest` و`truncated`
   و`hasMore`. هذه هي الأداة الوحيدة الكاشفة للمحتوى.

4. **Verify** — قبل الاقتباس من الأدلة المجهزة:

   الأداة `contextvault_verify`:

   ```json
   { "envelopeId": "<from-prepare>", "checks": [{ "kind": "source_freshness" }] }
   ```

   تعيد نتائج حتمية لكل فحص: `valid` أو `stale` أو `invalid` أو
   `unavailable`.

5. **Stats** — عدّادات دقيقة خاصة بالعملية:

   الأداة `contextvault_stats` بمدخل فارغ صارم `{}`.

6. **Purge** — حذف الحالة المشتقة على خطوتين:

   استدعِ `contextvault_purge` بوضع `preview` وهدف لتتلقى
   `purgeIntentId`، ثم استدعِها مجددًا بوضع `execute` ومعرّف النية نفسه.
   الملفات الأصلية لا تُمس أبدًا.

كل خطوة استدعاء MCP مستقل. الترتيب أعلاه مسار موصى به وليس سلسلة داخلية؛
وكل استدعاء يُعاد التحقق منه من الصفر.

## 7. الأخطاء الشائعة

| رمز الخطأ                      | المعنى والاستجابة الأولى                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------- |
| `CV_INPUT_INVALID`             | الطلب خالف مخططًا أو سياسة. صحّح شكل المدخل.                                                   |
| `CV_AUTHORIZATION_DENIED`      | `rootId` مجهول، أو لم تُصرَّح جذور عند البدء. الجذور عند البدء فقط.                            |
| `CV_PATH_OUTSIDE_WORKSPACE`    | المسار يهرب من الجذر المصرح به (مقاطع `..` أو رابط هارب). ابقَ داخل الجذر.                     |
| `CV_PATH_ABSOLUTE_DENIED`      | المسارات المطلقة غير مقبولة داخل المسار النسبي.                                                |
| `CV_PATH_REPARSE_POINT_DENIED` | عُبِر رابط رمزي أو وصلة. مرفوض بالتصميم.                                                       |
| `CV_PATH_SPECIAL_FILE_DENIED`  | الهدف ليس ملفًا عاديًا (جهاز أو FIFO أو socket أو مجلد).                                       |
| `CV_RESOURCE_SOURCE_TOO_LARGE` | الملف يتجاوز حد قراءة المصدر (32MiB افتراضيًا وسقف صارم 64MiB). مرفوض بالتصميم.                |
| `CV_SOURCE_CHANGED`            | الملف تغيّر أثناء الفحص. أعد الفحص وجهّز مغلفًا جديدًا.                                        |
| `CV_CAPABILITY_INVALID`        | قدرة مجهولة أو منتهية أو مسحوبة أو غير مطابقة. جهّز مغلفًا جديدًا؛ ولا تجرّب تنويعات.          |
| `CV_RETRIEVAL_POLICY_DENIED`   | نوع المحدد أو البايتات المطلوبة تتجاوز السياسة الممنوحة. ضيّق الطلب أو أعد التجهيز بمنحة أوسع. |
| `CV_ENVELOPE_NOT_FOUND`        | المغلف انتهت صلاحيته (TTL) أو مُحي أو المعرّف خاطئ. أعد التجهيز.                               |
| `CV_PURGE_INTENT_INVALID`      | التنفيذ يتطلب `purgeIntentId` من `preview` سابقة بالهدف نفسه.                                  |
| `CV_OPERATION_CANCELLED`       | أُلغي الطلب عبر إشارة الإلغاء. قابل لإعادة المحاولة.                                           |
| `CV_INTERNAL_ERROR`            | حالة داخلية غير متوقعة. أعد المحاولة مرة؛ وأبلغ إن تكررت.                                      |

كل فشل هو مغلف `CV_*` بلا محتوى ومعه معرّف ارتباط و`isError: true`.
الرسائل لا تحتوي مسارات أو محتوى مصدر أو أسرارًا أو رموزًا أبدًا.

## 8. حدود الأمان التي ستقابلها

هذه الحدود من التنفيذ نفسه لا من التسويق:

| المورد                            | الحد الحالي                         |
| --------------------------------- | ----------------------------------- |
| قراءة المصدر                      | 32MiB افتراضيًا وسقف صارم 64MiB     |
| ناتج الاسترجاع                    | 1MiB كحد أقصى                       |
| المغلفات النشطة                   | 64 مغلفًا                           |
| الحالة المشتقة في الذاكرة         | 4MiB إجمالًا                        |
| البيانات الوصفية المتسلسلة للمغلف | 256KiB                              |
| مدة صلاحية المغلف                 | 60–7200 ثانية؛ الافتراضي 1800 ثانية |
| التجهيزات المتوازية               | عمليتان افتراضيًا والسقف 4          |
| مهلة التحضير والاسترجاع           | 30 ثانية لكل عملية                  |
| مقاطع المغلف                      | 1024 مقطعًا × 4096 بايت للمقطع      |
| فحوص التحقق                       | 16 فحصًا لكل استدعاء                |
| نوايا المحو المعلقة               | 16 نية                              |

عند بلوغ أي حد يفشل الخادم بإغلاق آمن برمز `CV_*` محدد. لا يوجد أي إعداد
لتجاوز سقف صارم.

## 9. إيقاف الخادم وتنظيف الحالة المؤقتة

- أوقف الخادم بإنهاء العملية بالطريقة التي ينهي بها مضيف MCP عملياته
  (غلق النقل أو إنهاء العملية الابنة). لا توجد خدمة خلفية تُوقف ولا منفذ
  يُغلق.
- كل الحالة المشتقة — المغلفات وبصمات رموز القدرة وسجلات المنشأ والعدادات
  ونوايا المحو — في ذاكرة العملية فقط، وتُطرح عند خروج العملية. لا شيء
  ينظف على القرص.
- لإسقاط الحالة مبكرًا استخدم `contextvault_purge` (القسم 6 الخطوة 6) أو
  أعد تشغيل العملية.
- لا يُكتب أي شيء خارج ذاكرة العملية في أي لحظة: لا سجلات، لا ملفات
  تخزين مؤقت، لا قاعدة بيانات.

## 10. تذكير بالنطاق

- لا حزمة npm منشورة؛ التثبيت من المصدر فقط.
- لا مستمع شبكي ولا تتبع ولا نداءات خارجية ولا استمرارية.
- لا كتابة ملفات ولا تنفيذ أوامر، إطلاقًا.
- التصنيف تقديري ومتحفظ؛ والقيم المطابقة للأسرار لا تُعاد ولا تُسجَّل.
- التحقق يثبت الاتساق الداخلي، لا صدق أي عبارة.
